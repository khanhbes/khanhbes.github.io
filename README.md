## Giới thiệu

Website là hồ sơ năng lực trực tuyến của **Khanh**, tập trung vào **Artificial Intelligence**, **Computer Vision** và **phát triển ứng dụng di động**. Portfolio trình bày thông tin cá nhân, quá trình học tập, kinh nghiệm, bộ kỹ năng và các sản phẩm tiêu biểu theo một giao diện trực quan, hiện đại và tương thích với nhiều kích thước màn hình.

> Truy cập trực tiếp: **[https://khanhbes.github.io](https://khanhbes.github.io/)**

## Nội dung nổi bật

- Giới thiệu chuyên môn và định hướng phát triển.
- Tổng hợp kỹ năng về AI, Computer Vision, Flutter và hệ sinh thái liên quan.
- Trình bày các dự án với mô tả, công nghệ và liên kết mã nguồn.
- Thông tin học vấn, kinh nghiệm và kênh liên hệ.
- Hiệu ứng tương tác, animation và bố cục responsive.

## Chạy trên máy cá nhân

```bash
git clone https://github.com/khanhbes/khanhbes.github.io.git
cd khanhbes.github.io
```

Sau đó mở `index.html` trực tiếp trong trình duyệt hoặc chạy bằng một local development server, chẳng hạn extension **Live Server** của Visual Studio Code.
